# 检查对焦读写与回位重复性

本检查先收集设备证据，不假定相机支持可靠的对焦读数。不会修改定位配置或内参；对焦控制请求会改变设备状态，驱动可能在退出后保留设置，下一次采集前应核对所需模式。

## 准备与启动

关闭占用相机的定位程序。将相机和 9×6 内角点棋盘分别固定在支架上，不用手持。棋盘完整入镜、照明稳定，避免反光；先选能够清晰检测整板的距离。

```powershell
python -m calibration.focus_probe capture
```

默认使用配置中的相机 1、640×480、旋转 180°，先尝试 Windows DirectShow 后端。启动时只读取对焦状态，不自动切换模式。界面 `focus` 是驱动回读，`AF` 显示 AUTO/MANUAL/UNKNOWN，并保留原始 raw 值。DirectShow 的 raw=1 表示自动、raw=2 表示手动；布尔式后端一般为 1 开、0 关，不能混用。这些读数不能单独证明硬件状态；不假定焦点范围为 0–255。

无法连接或读写不响应时，可关闭窗口后分别比较：

```powershell
python -m calibration.focus_probe capture --backend msmf
python -m calibration.focus_probe capture --backend any
```

## 第一步：确认接口能否影响镜头

1. 按 **A** 请求自动对焦，等待图像清晰、焦点读数稳定。若需检查自动对焦读数是否变化，可以先移动目标测试，正式重复性采集前必须重新固定目标。
2. 按 **M** 请求关闭自动对焦。核对控制台 `set` 返回和窗口显示 `AF=MANUAL`（DirectShow 通常 raw=2），并观察焦点是否保持。手动模式回读并不能单独保证物理镜片已稳定。
3. 按 **B** 记住当前焦点读数，作为返回目标。倒计时结束后确认稳定，连续按 **S** 保存三张，作为固定状态下的基线。
4. 按几次 **]** 增大焦点值，或 **[** 减小焦点值。每次等待镜头稳定，观察 requested、focus 回读及画面清晰度/倍率。默认一次增量 5；它不是设备范围或实际步长。若设置被拒绝、被截断或没有变化，检查驱动范围/步长；必要时使用厂商工具。可调整 `--step 1` 或 `--step 10`。
5. 至少验证两个不同焦点。某个值一直显示 0、所有值回读一样或画面完全无变化时，不能宣告接口可靠；也不能仅凭 0 就认定不支持。

脚本记录每次请求值、set 返回值、立即回读，以及保存图片时的延迟回读，便于区分“命令接受”和“稍后反馈”。读数不是镜头编码器，也不是帧曝光时的焦点元数据。

## 第二步：检查回到同一值能否重复

相机和棋盘保持固定，执行 **基准焦点 A → 其他焦点 B → 基准焦点 A**：

1. 上面已用 B 键记住基准，并按 S 保存三张。这里“焦点 A/B”是状态名称，不是键盘 A/B 键。
2. 按 ] 若干次离开基准，等待稳定后按 S 保存。
3. 按 **R** 请求回到记住的基准值，确认读数相同、画面稳定，再按 S 保存三张。
4. 重复三轮。条件允许时分别从较大值和较小值返回，观察是否存在方向相关的回位差异。不要为了清晰而打开自动对焦，它会破坏固定焦点比较。
5. 按 **Q** 退出并自动生成报告。记录采集期间是否有触碰相机、棋盘或灯光变化；这些会干扰解释。

保存图像无需角点检测成功，可用于检查明显失焦状态；只有按实际后端解码为手动模式、焦点回读完全相同且完整棋盘检出成功的样本，才参加角点重复性比较。旧 DirectShow 会话重新 analyze 时，会按 session.json 后端将 raw=2 正确解释为手动模式，无需改写原始日志。

## 输出与判断

每次产生 `calibration/focus_checks/session_时间/`，包含原始 PNG、控制请求日志 `events.json`、保存时读数和角点 `samples.json`、`repeatability.csv`、`summary.json` 与 `检查报告.md`。清晰度只作辅助，不等于焦点位置或内参。

重点比较同焦点静止连续保存的基线，与“离开再返回”的图像：

- **角点 RMS（px）**：绝对图像坐标差，允许棋盘角点顺序整体反转，不做图像对齐。
- **中心位移（px）**：棋盘角点集合中心变化。
- **相对尺度变化（%）**：角点相对其中心的均方半径变化，可辅助发现成像倍率变化。

回位差异应与连续静止帧本身的检测波动相当，不能用一个固定通用阈值判断所有相机。若不同焦点的回读、画面变化均可确认，且同值回位有良好重复性，才有基础继续做多焦点内参标定。这些检查也不能证明 focus 回读与每帧曝光严格同步。

反复分析已保存会话：

```powershell
python -m calibration.focus_probe analyze "calibration/focus_checks/实际会话目录"
```
