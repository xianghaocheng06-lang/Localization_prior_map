该项目使用单目apriltag视觉定位和三个红外距离传感器进行软体机器人在机翼模型中的定位。
视觉定位可以输出相机的位置和姿态，而红外器件返回机器人前端盖中心坐标系下，机器人前面的平面到原点的距离和法向量坐标。
这次实验使用动捕作为基准测试相机视觉定位和红外的误差。
positioning_records.csv记录了相机视觉定位的位姿和红外等信息。
markerPos_test_1.mat里是动捕记录的marker点坐标。每组有6-7个点。
其中三个点固定在机翼模型上，另外四个点固定在机器人上，不过有时候机器人上四个点不能全部采集到，所以有的组只有6个marker点
三个固定在机翼模型上的点在其坐标系下的坐标分别为(553,241,128),(365,7.5,128),(638,3,128)
四个固定在机器人上的点在其坐标系下的坐标分别为(-34.34,-10.29,-1.2),(-17,-27.2,1.5),(17,-27.2,1.5),(34.34,-10.29,-4.2)
每组动捕的前三个是机翼上的点，但我不知道对应关系，后三或四个是机器人上的点，同样不知道对应关系
从第七组开始机翼上的三个marker点才是对的，前面的几组这三个marker点有问题
注意，通过marker点拟合机器人位置时，如果只有三个点的数据，一定要遍历所有4选3的可能性，然后判断哪种是对的，而不是直接用三个点拟合四个点
